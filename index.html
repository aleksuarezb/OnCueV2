Help & User Guide

  1. Pick your role. MD can add songs, build setlists, and push the live chart to everyone. Viewer follows along automatically.
  2. Add a song (MD only): Library → "+ New Song". Enter a title, then add one or more chart versions — type the chart exactly as it should look on stage. A version named "Numbers" is shown by default.
  3. Build a setlist (MD only): Setlists → "+ New Setlist" → add songs from the library, reorder with the arrows.
  4. Go live (MD only): open a setlist and tap "Go Live" — every Viewer who's following jumps to that song automatically.
  5. Navigate: swipe left/right on the chart, or use the arrows on the right edge, to move through the setlist.
  6. Chart modes: tap the ☀︎ icon on the chart screen to switch between dark and light display.
  7. Switch identity anytime by tapping the OnCue logo in the header.
